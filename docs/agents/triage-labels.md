# Triage Labels

| Canonical role | Tracker value | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Waiting for maintainer evaluation |
| `needs-info` | `needs-info` | Waiting for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for implementation |
| `ready-for-human` | `ready-for-human` | Requires human judgment, access, or action |
| `wontfix` | `wontfix` | Intentionally not being implemented |

When a skill names a canonical triage role, write the corresponding tracker value in the issue's `Status:` field.

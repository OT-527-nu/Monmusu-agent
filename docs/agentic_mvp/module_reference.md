# 《逃离塔纳里昂》模组参考书

## 速查页（开场后五分钟）

- **一句话前提**：海难幸存者被关进梦境海滨城塔纳里昂的废弃石牢；他们必须在城市开始注意他们之前，决定相信谁、追逐什么，以及用什么方法离开或改变眼前的处境。
- **核心循环**：读懂玩家意图 → 决定如何兑现 → 交付一个新的选择。掷骰只是兑现工具之一，不是必经关卡（详见 [GM 能力章程](gm_prompt.md)）。
- **谁在哪**：玩家调查员 + 维斯佩拉（伤翼夜魇修女）、萨芙拉（受寒蛇人学者）、阿兰妮丝（脱水织网者）同关石牢；商人惨叫后生死未定；唯一船工提灯离开；拾骨者游荡在街巷；拉提是城市性的环境恐怖核心。
- **第一幕节拍**：越狱 → 追查惨叫或另寻出路 → 城市开始回应玩家的具体选择。
- **门印逻辑（一条可发现的机关，不是必走答案）**：门印「千塔面」迎客、「远海面」送船；把远海面朝向外海、让青羽鸟指向水面、两侧绞盘近乎同时运转，可开启离城潮流。工具、魔法、破坏、交易或新发现都可以改变操作方式。
- **压力-释放节奏**：拉提的注视按「征兆逼近 → 释放/转向」交替，不要只升不降（见「拉提的注视」）。
- **三条红线**：除「开场最小正典」外，本文内容都是参考条目，GM 确立后才成为本局正典；本文不是行动菜单；威胁没有数值时钟。

## 文档定位与使用方式

这是供 GM 全文阅读的短篇模组参考书。它提供一座城市、一个开场困境、若干人物、秘密、地点、意象与发展灵感，帮助 GM 即兴主持一局能够收束的《逃离塔纳里昂》。

除「开场最小正典」一节外，本文内容都是**参考条目**。参考条目不会因为写在这里就自动成为本局事实。GM 可以采用、组合、改写或舍弃它们，也可以创造本文没有写到的人物、地点、路线、代价与答案。GM 一旦在叙述或隐藏裁定中明确确立某项内容，它才成为本局正典，并应在后续游戏中持续成立，直到虚构中的事件改变它。

本文按「条目卡」组织：速查页 → 体验核心 → 开场正典 → 开场节拍 → 演员表 → 地点卡 → 秘密 → 人物 → 威胁卡 → 揭示卡 → 随机表 → 可能的发展 → 机械 → 收束 → 开放问题。地点卡、威胁卡与揭示卡是为主持当下快速定位而设的**可用素材**，不是剧情许可层；它们不包含 `fact_id`、`mechanic_id`、路线状态、解锁标记或结局 ID。

本参考书不是行动菜单。玩家提出本文没有预写的合理行动时，GM 应认真判断它在当前世界中会造成什么，而不是把行动引回某条预定流程。

队友的详细扮演资料见[角色与预生成调查员](characters.md)。COC 机械与最终事实记录的结构见[数据契约](contracts.md)。

## 体验核心

塔纳里昂是一座美得足以让人忘记逃跑的海滨梦城。宏伟高墙、尖塔、神殿、浮雕与集市共同许诺着不可复制的奇观；无人收殓的白骨、没有正常人类的街道和反光表面中迟来的面孔，则说明这份美丽从未打算把来客送回去。

本局的核心困境不是「找出唯一出口」，而是：一群刚从海难和囚禁中活下来的同行者，在城市开始注意他们之前，要决定相信谁、追逐什么，以及愿意用什么方法离开或改变眼前处境。

适合维持的基调包括：

- 华美与腐败同时出现，诱惑本身比突袭更危险。
- 恐怖来自错误认知、迷路、沉默、倒影和逐渐被注视的感觉。
- 城市很危险，但玩家的巧思仍能真正改变局势。
- 同伴有自己的欲望、恐惧与判断；他们可以争论和行动，也会尊重调查员的主动选择。
- 结局应来自本局已经发生的因果，而不是从预设答案中挑选。

## 开场最小正典

以下内容在第一次玩家输入前已经成立。它们是本参考书中唯一预先要求成为本局正典的内容。

实现期 `SessionSetup` 会把这些内容拆成可独立结束的自然语言事实并分配 `fact_id`，例如「牢门仍然锁着」和「武器、工具与大部分随身物品已被收走」必须是不同记录。这个很小的 opening seed 只负责可追溯初态，不把后续参考内容结构化为剧情权限。

### 公开事实

- 玩家控制的调查员与维斯佩拉、萨芙拉、阿兰妮丝同乘一艘押送俘虏的商船。船在塔纳里昂外海触礁，幸存的绑匪把四人带进城中，关进码头附近的一间废弃石牢。
- 四人的手脚可以活动，牢门仍然锁着。武器、工具与大部分随身物品已被收走；每个人仍穿着普通衣物，并保留未被发现的私人小物。
- 四人已经交换了姓名、种族与自报身份，也共同经历了海难。阿兰妮丝曾在海浪中用蛛丝把四人和一段断木连在一起；维斯佩拉的伤翼、萨芙拉的受寒与尾部擦伤、阿兰妮丝的脱水和蛛丝消耗都是眼前可见的状态。
- 被押入城市的沿途没有出现正常人类居民。四人见过高墙、潮湿石道和无人埋葬的白骨，但没人知道可靠的离开方法。
- 入夜后，牢外传来绑架他们的商人短促而凄厉的惨叫。唯一还在看守的船工提灯离开，脚步与灯光正在远去。牢门依旧锁着，附近暂时无人看守。

### 主持边界

玩家拥有调查员的台词、主动选择、信念与关系承诺。GM 呈现感官信息、扮演其他角色并裁定行动后果。这是跨模组的主持边界，不是虚构世界事实，也不写入事实账本。

### 开场时尚未确立的内容

开场不要求任何隐藏事实已经成立。惨叫的原因、商人是否死亡、失物在哪里、城市为何困住来客、同伴没有说出口的愿望，以及可行的离开方法，都可以等待 GM 根据玩家行动确立。本文后续提供的解释只是可用材料。

### 会话开场叙述

> 海难后的盐水仍从石缝间渗出。牢外忽然传来商人凄厉而短促的惨叫，唯一的灯光随船工的脚步远去。铁锁还扣在门上，但现在没有人守着你们。你打算怎么做？

内容作者可以在发布新的参考书修订前调整措辞与感官细节；一局创建后，`SessionSetup.opening_narration` 固定为该修订的这段文字，由 CLI 直接展示。第一个实质行动始终交给玩家，GM 从玩家首条输入开始主持。

## 开场与第一幕节拍

开场叙述已经给了「立即困境」（锁着的牢房 + 无人看守）。GM 不必在叙述里补背景，而是在第一回合就把「明确短期目标」和「自然语言威胁」压进玩家的眼前处境，并让玩家 30 秒内就有可做的事。

### 把三件套补足

- **立即困境**：铁锁还扣在门上，船工的灯光正在远去。
- **明确短期目标**：先离开这间牢房（撬锁、拆石缝、引回船工、求救、谈判……手段由玩家决定）。
- **自然语言威胁**：惨叫不是凭空发生的——某个东西正在码头区移动，而且不会永远走远。

这三件套是**主持提示**，不是要 GM 照读的固定开场白。开场叙述文字本身不变；GM 用自己的话在第一轮把短期目标与威胁讲清楚即可。

### 第一幕的可选节拍（可跳过、可重排）

- **越狱（到达，约 1–3 回合）**：把第一项行动当作玩家意图的第一次表达，让越狱方法与失败方式都留下痕迹。
- **追查或另寻（调查）**：离开牢房后，玩家可能先找装备、查惨叫现场、追踪船工或直奔海边。让选择改变「谁先遇见他们、哪些物品仍在原处」。
- **城市回应（领悟）**：一旦玩家做出留下痕迹的行动（弄出声响、带走城物、窥探秘密），拉提的注意第一次以可感知的征兆浮现。

每幕结束就剪掉，直接跳到下一个有意义的选择，不逐段结算路程。

## 地点条目卡

以下地点可以按任何顺序出现，也可以被跳过、移动、合并或扩写。玩家离开牢房后，城市不需要等待某个地点被「解锁」。每张卡的「玩家当下感知」可直接进入 `narration`；「立即钩子」给玩家一件可做的事；「可发生的复杂化」让失败或停留有下一幕。所有描述都是可用素材，不是本局已经成立的事实。

### 石牢与码头区

- **一句话印象**：海就在墙外，锁就在门里；逃跑的起点也是第一个证据现场。
- **玩家当下感知**
  - 看：潮湿石壁上的盐渍与水线；牢门铁锁；墙脚一道窄缝在涨潮时渗进海水；看守匆忙丢下的杂物。
  - 听：海浪拍打石堤的闷响；远处码头木桩的吱嘎；惨叫之后某种拖拽声逐渐远去。
  - 闻：海盐、湿灰泥、淡淡的灯油与生锈金属。
  - 触：石面潮湿冰冷；铁锁锈迹粗糙；地面有一层薄薄盐霜。
- **立即钩子**：船工的灯光正在远去，附近暂时无人看守——这是第一个自己动手的机会。
- **可发生的复杂化**：涨潮让窄缝灌进更多海水；船工折返取灯油；拖拽声突然转向牢门方向。
- **与其他地点关系**：邻接旧仓库（四人装备可能在其中）、系船石渠、通往高处门楼的狭窄阶梯，以及惨叫现场。

### 白骨街

- **一句话印象**：满地白骨不是装饰，是许多失败者留下的不同死法。
- **玩家当下感知**
  - 看：碎骨与灰白粉尘覆盖街面；墙脚刻着死者警告；骨骼姿势各不相同。
  - 听：自己的脚步踩碎骨片；风穿过空巷的哨音；偶有骨链摩擦石地的声音由远及近。
  - 闻：干燥的尘、旧灰泥、极淡的海腥。
  - 触：地面骨粉滑腻；某些骨片仍有温热（拾骨者刚经过时）。
- **立即钩子**：一具靠近海边、姿态不同的骸骨，其随身物指向某个还没被翻开的地方。
- **可发生的复杂化**：踩响骨片引来注意；认出死者身份带来道义负担；某具「骸骨」其实还保有一丝意识。
- **与其他地点关系**：连接码头区与千奇集市；越深入离海岸越远。

### 千奇集市

- **一句话印象**：每件奇物都像是为你准备的，摊贩却一个也不见。
- **玩家当下感知**
  - 看：拱廊与摊位上的梦境物件；墙面浮雕（潮流、千塔、船只、青羽鸟）；物件似乎随视线变化。
  - 听：极轻的织物摩擦、无风自动的铃铛；偶尔有人低声还价，回头却无人。
  - 闻：无法辨认的香料与旧纸；一丝梦醒时分的淡甜。
  - 触：物件表面温度不一，有的像刚被握过。
- **立即钩子**：一件对应调查员欲望的物件摆在最近处（失踪者的声音、证明学说的拓片、完好的翅膀、通往清醒世界的门缝）。
- **可发生的复杂化**：拿走物件招来拾骨者；交易货币不是金钱；物件开始回应持有者。
- **与其他地点关系**：墙面浮雕呼应门楼与阿卡利尔的意象。

### 阿卡利尔与门楼

- **一句话印象**：城市最稳定的一条海路，也最像一扇需要被理解的机关。
- **玩家当下感知**
  - 看：高墙与石砌码头之间的巨门；门楼内圆形凹槽、两侧绞盘、石锁传动；一条通往海面的狭窄水渠。
  - 听：门后水道被吞没般的闷响；绞盘空转的呻吟；远处浪声忽远忽近。
  - 闻：海盐、冷青铜、湿石。
  - 触：门印凹槽边缘有反复翻转的磨损；绞盘冰冷。
- **立即钩子**：门楼的圆槽与双面磨损暗示有一件东西曾被反复翻转、取走又放回。
- **可发生的复杂化**：机关错误改变潮向、点亮城市深处或引来居民；门印不在原位；需要多人协作才能同时转动绞盘。
- **与其他地点关系**：门印（千塔面迎客 / 远海面送船）、无帆引潮舟与门外水道。

### 无帆引潮舟

- **一句话印象**：一艘靠门印潮流、由骨链固定的狭长黑舟。
- **玩家当下感知**
  - 看：狭长黑舟无帆；船舱空间大致容纳四名普通体型乘客；船头有青羽鸟纹。
  - 听：骨链随潮水轻响；船底与礁石摩擦的细碎声。
  - 闻：海水、旧木、骨粉。
  - 触：船身湿滑；骨链冰冷且异常结实。
- **立即钩子**：它既是现成的交通工具，也是拾骨者的工作场所——用它，或问它的主人。
- **可发生的复杂化**：船是残骸需要修理；拾骨者正在用它回收海难遗物；人数、承重与损伤随当前虚构变化。
- **与其他地点关系**：门楼下方水渠、礁区、拾骨者的活动路线。

### 城市深处

- **一句话印象**：越深入，离海岸越不可靠，城市越会拿你在意的东西诱惑你。
- **玩家当下感知**
  - 看：神殿、高塔、花园、剧场与远处灯火；越深入，反光表面越多。
  - 听：熟悉的声响从深处传来，方位却每次都不一致。
  - 闻：海腥味被一种更淡、更旧的甜味取代。
  - 触：方向感开始失灵；光滑金属与积水里出现不应有的倒影。
- **立即钩子**：一个只对某位同行者/调查员有意义的声响或气味，从深处飘来。
- **可发生的复杂化**：迷失方向；诱惑加剧；也可能发现新盟友、路线或真相，让「离开」不再是唯一目标。
- **与其他地点关系**：连接所有其他地点；越深入，回到海岸的路越不可靠。

## 参考秘密与矛盾

以下解释能够把旧有素材连接成一条有力因果，但它们在 GM 确立前都不是隐藏正典。

### 商人的计划

外貌古怪的商人原本打算把调查员带到月之暗面，作为献给奈亚拉托提普的祭礼。他以真实的古碑拓片诱骗萨芙拉，希望强迫她翻译航路与献祭文字；他要求阿兰妮丝制作囚禁「活货」的束具，在她拒绝后将其绑走。维斯佩拉发现这场绑架，在没有明确神谕要求的情况下自行营救众人，也因此被捕。

这段背景适合解释四人的共同处境和各自伤痕，不要求本局继续追查奈亚拉托提普、教团或月之暗面。GM 也可以根据玩家追问，改变商人的买家、目的或仍在活动的同谋。

### 海难与巨门

商船没有沿阿卡利尔门前较平静的水道靠岸，而是在巨门侧面的危险水域触礁。幸存者被海浪抛上礁岸，再由绑匪带进城中。

一种解释是，商人进入门楼后撬走了一枚双面青铜门印，以为那是财宝。门印离位使巨门关闭，也使门外水道被乱流与浓雾吞没。负责回收尸骨和城市物件的拾骨者随后追上商人；开场惨叫正是这次相遇的结果。

GM 可以采用完整解释，也可以只采用其中一部分。商人可能尚有一口气、已经逃进别处、被船工背叛，或故意用惨叫诱走看守。重要的是让后续真相与玩家发现的证据一致。

### 拉提是什么

拉提可以是拥有独立意志的存在、城市本身的意识、倒影传播的认知灾害，或所有目击者共同给出的名字。其完整形貌不适合作为可安全观察、解释或正面对抗的普通怪物。

角色可以接触拉提留下的痕迹、影响、幻象、欲望和不完整显现。是否存在与拉提交涉、蒙骗、献礼或脱离其注意的方法，留给本局行动决定。

### 城市为何允许离开

阿卡利尔为何有一条相对稳定的航道、拉提为何容忍巨门存在、门印由谁制造，都可以保持开放。可能的答案包括：巨门早于拉提；城市需要来客传播它的梦；离开也是诱惑的一部分；拉提无法理解主动放弃秘密的人；或某位旧神在城市法则中留下了一道裂隙。

这些答案可以成为后续揭示，也可以永远没有唯一解释。

## 人物与存在

完整人格、秘密、说话方式和机械卡见[角色与预生成调查员](characters.md)。这里的摘要用于快速唤起，不是人物的全部。

### 三名同行者

维斯佩拉、萨芙拉与阿兰妮丝是持续同行的 NPC，由 GM 直接扮演。她们会观察、提出意见、彼此接话、在合理情境中行动，也会因恐惧和欲望作出不完美的判断。她们不替调查员选择路线、说出台词或作出关系承诺。

### 外貌古怪的商人

商人把生命、知识与身体都看作可以标价的货物。他贪婪、善于发现别人想要什么，却高估自己控制未知事物的能力。开场惨叫之后，他可以成为尸体、伤者、逃亡者、诱饵、暂时的谈判对象，或一连串误导性证词的来源。

他随身可能有牢房钥匙、仓库线索、航海札记、俘虏用途记录、违禁货物和从城中拿走的物件。GM 应让具体物品回应玩家怎样寻找，而非等待唯一正确搜查方式。

### 幸存船工

船工恐惧这座城市，仍可能因习惯、债务或惧怕惩罚而忠于商人。他知道押送过程和海难片段，却不理解拉提或塔纳里昂的全部真相。

他可以逃走、投降、撒谎、求同行、抢夺补给、试图救商人，或在面对拾骨者时彻底崩溃。若玩家与他建立了真正的关系，他也可以超出「短暂追兵」的旧角色，成为盟友、负担或收束中的重要人物。

### 拾骨者

拾骨者是瘦长、四肢关节过多的非人存在，脸上覆盖刻着安详笑容的鎏金面具。它们拖走尸体、整理白骨、回收从城市取走的物品，骨链摩擦石地的声音常比它们更早出现。

它们不必见人就杀。它们可能无视守序离开的闯入者，追逐持有城市物件的人，与愿意归还某物者交换，遵循难以理解的搬运礼仪，或把活人误认为尚未完成的尸体。它们通过响动、痕迹、遗失物和拉提的注意寻找目标，因此可以被观察、误导、阻挡或交涉。

### 幻灵拉提

拉提更适合作为环境性恐怖核心，而非等待被击败的敌人。它可以借高处灯火、错误影子、雕像视线、延迟倒影、梦中召唤和居民突然一致的动作触及场景。

拉提是否「想要」什么，应由 GM 随本局发展赋形。它可能被窥探激怒，被来客的欲望吸引，希望留下某个人，或只是像光照到尘埃一样注意到了他们。

### 其他居民

塔纳里昂可以容纳引路者、收藏家、无声摊主、维护建筑的怪物、仍保有人类习惯的旧来客，以及只在某种感官中存在的居民。它们可以帮助、诱骗、做交易或提出新的问题，不需要属于预先定义的阵营。

## 威胁条目卡：拉提的注视

拉提的注意随虚构变化，不对应固定数值。它按「越轨源 → 征兆 → 显形 → 驱逐/转向 → 沉睡」这条自然语言生命周期移动；GM 从各栏自由选取、改写和重排，不把它们当成数值时钟。

### 越轨源（什么会引来注意）

喧闹、久留、亵渎、携带引人注意的城市物件、主动窥探秘密，或在倒影前暴露。

### 征兆（注意正在逼近，可任意重排）

- 遥远浪声与无法定位的脚步忽然同步。
- 倒影比本人慢半拍，面具与雕像似乎转向角色。
- 高塔的苍白窗灯一扇接一扇亮起，影子开始违背光源。
- 角色在积水中看见自己的白骨、未曾做出的选择或最想得到的事物。
- 街道悄然把人引向城市深处，熟悉路标从背后再次出现。
- 拾骨者不再漫无目的地工作，而是沿着角色留下的痕迹聚拢。
- 苍白光线扫过街面，光滑金属中出现不完整且无法记住的轮廓。
- 所有反光表面同时表现出同一个视角，仿佛整座城市终于看清了来客。

### 显形（它如何触及场景）

借高处灯火、错误影子、雕像视线、延迟倒影、梦中召唤，或居民突然一致的动作。

### 驱逐 / 转向（如何缓和或引开）

遮蔽反光、改变位置、放弃诱惑、误导追踪者、完成某种礼仪，或理解拉提的欲望。

### 沉睡（何时不再紧迫）

玩家脱离注意、找到遮蔽，或拉提的欲望得到满足、转移。

### 压力-释放节拍

威胁不应只升不降。按「到达(不安) → 调查(张力) → 领悟(恐惧) → 对峙(恐怖) → 余波(释放/腐化)」排节奏：

- **不安**：矛盾细节（微笑却不看眼的摊主、没有鸟虫的广场、带锈味的花）。
- **张力**：玩家发现证据证明「这不只是怪」。
- **恐惧**：威胁从「在场」变为「逼近 / 不可避免」。
- **恐怖**：一次短促的对峙或逼近，逼出玩家的代价与抉择。
- **释放 / 腐化**：安全、善意、美或日常琐事让玩家喘一口气；**在释放里埋一个「错误细节」**（好心的居民说了句事后想来毛骨悚然的话、美好瞬间里有一处感官谎言），让释放本身成为下一次不安的种子。

征兆不必依次出现，也不必只会升级。让玩家能从叙事理解危险为何变化，并保留在最后关头采取行动、付出代价或改变局势的机会。

## 揭示条目卡（可移动的证据与意象）

下面的素材可以出现在任何合乎因果的位置，用来支持调查和联想，不是必须收集的清单。每条揭示按「结论 + 至少三个入口 + 玩家可自造的新来源」组织，并按 GUMSHOE 分「核心 / 氛围 / 深挖」三档：核心揭示能推进短篇，玩家以任意合理行动都能兑现，不锁单一技能；氛围揭示只营造感觉；深挖揭示奖励进一步的探查。一次失败不需要让有趣信息永久消失——让速度、暴露、误解、伤势或资源成为真正后果，也可以让同一真相从不同证人、痕迹和地点得到互相矛盾的版本。

### 核心揭示：门印离位使巨门和水道失去稳定

- 入口 A：商人札记记录他撬下圆盘后巨门闭合、平静水道翻涌。
- 入口 B：门楼圆形凹槽与双面磨损说明某件东西曾被反复翻转、取走又放回。
- 入口 C：船工或幸存者证词描述触礁前后的水道变化。
- 玩家可自造来源：只要当前正典支持，允许现场出现新证据（新的磨损、新的证人、新的痕迹）。
- 发现后玩家能做什么：尝试修复、交易、破坏、绕行，或改写目标。

### 核心揭示：开场惨叫与拾骨者追讨门印有关

- 入口 A：惨叫现场的尸体、拖拽痕迹、细白骨粉与散落物件。
- 入口 B：商人札记中「被追上」的只言片语。
- 入口 C：拾骨者沿商人留下的痕迹聚拢的方向。
- 玩家可自造来源：新的目击者、被拾骨者误认或交换得来的证词。
- 发现后玩家能做什么：与拾骨者交涉、归还门印、利用追讨节奏，或借机脱身。

### 氛围揭示：城市的诱惑从何而来

它可能来自拉提、城市本身、梦境法则，或奇观对欲望的自然放大。GM 根据调查员的背景钩子和本局经历，让诱惑呈现为只对这个人有意义的东西。这一揭示可以保持未知，不必给出唯一答案。

### 深挖揭示：城市为何允许离开

多个入口：门楼凹槽与双面磨损、绞盘浮雕或受力痕迹、青羽鸟图案的反复出现、白骨警告残句，或居民对旧城市法则的只言片语。可能答案见「城市为何允许离开」，也可以永远没有唯一解释。

### 其他可移动意象

- 市集浮雕可以表现旅人随千塔进入、船只随远海离开；也可能只是某个旧文明对潮汐的理解。
- 青羽鸟图案可以反复出现在路面、拱门、船首或梦中，鸟喙常朝向海风与阿卡利尔。
- 白骨警告可以写着「灯亮时低头，不要相信水中的脸」，也可以针对本局威胁留下别的残句。
- 倒影慢于本体、影子背离光源、鎏金笑脸在不同巷口重复出现，都能让角色判断某种注意正在靠近。

## 可能的发展

以下内容用于启发 GM 接住行动，不构成流程顺序。每一条都同时给出「失败或拒绝之后如何产生新选择」。

### 越狱与第一次选择

调查员可能撬锁、偷钥匙、拆石缝、利用尾巴或蛛丝勾取物品、诱骗返回的船工、呼救、等待、谈判，或提出完全不同的办法。牢房用于给第一项行动一个可理解的阻力，而不是测试玩家是否猜中预设解法。

失败或拒绝之后：让局面向前移动——门锁被撬出动静、涨潮逼近、船工折返——并打开一个新的选择，而不是把同一堵墙再问一遍。

### 追查惨叫

惨叫现场可以把商人、拾骨者、门印和仓库连接起来，也可以揭开另一条因果。若玩家救助商人，他可能用信息换命；若玩家忽略现场，相关物件与证据可以随尸体、船工或拾骨者移动，而非凭空等待。

失败或拒绝之后：让玩家获得核心发现，但付出速度、暴露或误解的代价；或让同一真相以互相矛盾的版本再次出现。

### 面对奇观

城市应提供真正值得犹豫的事物，而不只是明显的陷阱。接受诱惑可能带来有用知识、力量、关系或新目标，同时让角色欠下代价；拒绝诱惑则可以显露人物优先级。萨芙拉对发现的渴望、维斯佩拉对神意与个人愿望的困惑、阿兰妮丝对永不失效之网的想象，都能与调查员自身的背景形成镜面。

失败或拒绝之后：拒绝诱惑不是结束——它让城市把诱惑换成另一种形式，或让某位同行者对调查员的选择表态。

### 使用阿卡利尔

玩家若取得门印、理解意象并前往门楼，可以尝试恢复离城潮流。双绞盘、骨链、受伤的同伴和逼近的拾骨者适合形成一次多人协作，但具体分工应由人物位置、工具和玩家计划自然产生。

机关错误可以改变潮向、点亮城市深处、引来居民、损坏工具或要求新的取舍，而不必永久毁掉所有机会。正确理解也不要求额外掷骰；只有在结果不确定且失败确有意义时，GM 才选择 COC 机械。

### 创造另一条路

玩家可能修复商船、夺取拾骨者的交通工具、从高墙外下降、寻找梦境出口、召来海上存在、说服拉提放行、用城市奇观交换自由，或干脆改变目标。GM 应追问方法、资源与风险，然后让世界作出具体回应。

新路线不需要先得到参考书许可，也不应仅作为受罚后返回阿卡利尔的绕路。只要它在本局逐步建立的因果中成立，就可以成为真正的解决方案。

### 与城市建立关系

玩家可能不再以逃跑为唯一目标：他们可以解放某些居民、接替一项职责、留下研究、交还被盗之物、交换记忆，或把塔纳里昂的一部分带入清醒世界。让同伴对此产生真实分歧，并让玩家决定调查员的承诺。

## COC 机械的使用

本参考书不预先指定行动对应的技能、难度或结果。GM 先理解调查员具体想做什么；只有当结果不确定、失败会产生有意义的后果且机械能增加张力时，才选择相应的 COC 工具，并在结果产生前说明风险。

城市恐怖可能触发理智检定，追逐、坠落、战斗或机关事故可能造成伤害，危险尝试可能需要普通或孤注一掷检定。具体参数来自当前虚构和角色卡，由 Agent Harness 按[数据契约](contracts.md)结算。机械结果一旦产生就是本局事实，GM 应将其转化为新的叙事机会。

不需要检定的事同样重要：已经掌握充分证据后的正确判断、没有压力的普通移动、取回明确属于自己的物品，以及精彩计划已经消除主要不确定性时，可以直接成立。

## 收束灵感

短篇在核心困境获得叙事答案时收束。下面只是可借用的画面，不是完整结果列表：

- 众人乘某种船穿过分开的浓雾，塔纳里昂的灯火在身后依次熄灭或全部亮起。
- 一条由玩家创造的路线成功，但有人带走伤势、债务、梦中印记或一项真心选择的承诺。
- 调查员与城市、拉提、拾骨者或幸存者达成交易，离开不再意味着毫无牵连。
- 众人决定暂时留下、深入某个秘密或接替某项职责；短篇以一个明确的新生活或新困境结束，而非假装已经逃脱。
- 失败、死亡或直视不可承受之物后，调查员在清醒世界惊醒，只留下盐味、浪声、鳞片冷意或指尖蛛丝般的错觉。
- 调查员拒绝原本的逃亡目标，帮助同伴完成另一件更重要的事，并由本局因果给出独有结尾。

收束应回应玩家最重要的选择、至少一项已经形成的关系事实，以及塔纳里昂在本局被证明是什么。GM 可以结束会话，也应尊重玩家明确提出的继续或停止。

## 主持时值得记住的开放问题

这些问题比固定答案更有用：

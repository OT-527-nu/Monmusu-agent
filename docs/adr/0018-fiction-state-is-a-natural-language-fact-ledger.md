# ADR-018：虚构状态使用自然语言事实账本

- 状态：Accepted
- 日期：2026-07-26
- 决策关系：依赖 [ADR-008](0008-gm-narration-establishes-canon.md) 与 [ADR-009](0009-mechanics-in-tools-facts-in-final-response.md)

MVP 不把虚构世界预先拆成地点、NPC、线索、路线、时钟、旗标和结局等固定字段。GM 随最终答复提交自然语言事实变化：确立事实会把一个公开或隐藏的持续事实加入当前索引；结束事实会按稳定 `fact_id` 让旧事实停止描述当前世界，并记录结束原因。含义变化通过“结束旧事实，再确立新事实”表达。

Harness 生成事实 ID，记录来源回合并维护当前有效索引；完整事实历史保留在回合记录中，不因结束而删除。事实变化不包含任意数据路径或操作。只有 COC 角色数值等真正参与机械计算的数据使用严格 schema；更丰富的世界实体结构只有在真实试玩证明自然语言事实不足时才引入。

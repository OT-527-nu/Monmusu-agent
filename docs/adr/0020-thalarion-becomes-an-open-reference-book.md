# ADR-020：《逃离塔纳里昂》改为开放式参考书

- 状态：Accepted
- 日期：2026-07-26
- 决策关系：依赖 [ADR-012](0012-module-reference-is-prose-first.md)，取代现行模组对固定场景链、唯一正式路线和枚举结局的要求

MVP 保留《逃离塔纳里昂》的城市设定、开场困境、三名队友、主要人物、秘密、意象与潜在威胁，并将这些内容重写为 GM 可以直接阅读的开放式模组参考书。现有三场景流程、阿卡利尔逃生链、结局候选和“拉提的注视”时钟可以保留为可能发展或主持建议，但不再约束本局必须经过的路线、状态或结局。

GM 可以根据玩家行动创造参考书未预写的地点、人物、路线与收束，并将其确立为本局正典。新版模组的重要试玩场景是玩家提出并成功推进一条参考书未预写的解决路线；若系统仍把玩家导回固定流程，则不满足 MVP 方向。

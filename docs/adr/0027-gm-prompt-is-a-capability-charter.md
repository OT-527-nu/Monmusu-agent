# ADR-027：GM Prompt 是主持能力章程

- 状态：Accepted
- 日期：2026-07-26
- 决策关系：依赖 [ADR-005](0005-gm-authority-over-fictional-causality.md)、[ADR-015](0015-player-owns-investigator-intent.md) 与 [ADR-026](0026-minimal-gm-final-response.md)

GM System Prompt 以正向能力和主持职责为主：认真回应玩家提出的行动，把参考书当作灵感、把已确立事实当作正典，自由创造人物、地点、线索、威胁、代价与路线，在需要时选择 COC 工具并忠实承接结果，直接扮演 NPC 与队友，并保留玩家对调查员主动意志的控制权。

跨模组硬约束只保留机械结果不可篡改、正典连续性、玩家角色权和最小输出结构。Prompt 不再列出“不得开放新地点、不得改变路线、不得创造状态”等内容禁令，也不把主持建议提升为工具权限或工作流状态。

# ADR-028：关系由 GM 与自然语言事实维护

- 状态：Accepted
- 日期：2026-07-26
- 决策关系：依赖 [ADR-014](0014-gm-portrays-all-npcs.md) 与 [ADR-018](0018-fiction-state-is-a-natural-language-fact-ledger.md)

角色参考资料描述初始态度、欲望、恐惧、秘密、说话方式与关系边界；GM 根据本局真实经历自由发展信任、冲突、亲密、疏远或背叛。需要持续记住的关系变化作为公开或隐藏的自然语言关系事实进入事实索引，并通过完整回合记录保留形成过程。

MVP 删除关系阶段、升级条件、事件标签和 `pending_echo` 调度。GM 可以在合适时自然回顾旧事，不等待系统触发；只有未来产品明确需要数值化社交或恋爱规则时，才将其作为独立机械规则族评估。

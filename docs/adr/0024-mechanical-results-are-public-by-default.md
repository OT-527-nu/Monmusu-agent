# ADR-024：机械结果默认公开，秘密检定事前隐藏

- 状态：Accepted
- 日期：2026-07-26
- 决策关系：依赖 [ADR-006](0006-gm-chooses-mechanics-harness-resolves.md) 与 [ADR-023](0023-mvp-coc-mechanics-scope.md)

玩家主动声明的检定默认公开显示角色能力值、难度、骰点与成功等级；调查员 HP、SAN、幸运等自身数值变化始终公开。NPC 行动或会因骰点本身泄露秘密的机械判断，可以由 GM 在调用工具、产生随机结果之前标记为隐藏。

隐藏结果仍由 Harness 完整结算、记录并返回 GM，只是不立即展示给玩家。GM 不能看到结果后再改变其可见性，也不能用隐藏标记替代可信机械记录；后续何时通过虚构揭示隐藏结果由 GM 裁定。

# ADR-023：MVP 聚焦五类 COC 机械能力

- 状态：Accepted
- 日期：2026-07-26
- 决策关系：依赖 [ADR-017](0017-make-check-uses-character-sheet-and-coc-difficulty.md) 与 [ADR-022](0022-pushed-rolls-and-luck-are-player-choices.md)

最终 MVP 的 COC 机械范围包括普通技能与属性检定、孤注一掷、花费幸运、伤害与 HP，以及理智检定与 SAN。伤害工具由 GM 提供伤害表达式、原因和适用护甲，Harness 掷骰、更新 HP 并报告重伤、昏迷或死亡等规则结果；理智工具由 GM 提供成功与失败的损失表达式和恐怖来源，Harness 完成检定、更新 SAN 并报告相关规则阈值，具体虚构表现仍由 GM 裁定。

完整战斗轮、追逐、魔法、成长检定和规则书中的其他特殊系统不进入 MVP。这些能力未来可以作为新的通用 COC 语义工具增加，不要求改变单 GM Agent Loop、模组参考书或自然语言事实账本。

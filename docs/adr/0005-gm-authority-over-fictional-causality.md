# ADR-005：GM 拥有虚构因果裁定权

- 状态：Accepted
- 日期：2026-07-26
- 决策关系：局部取代 [ADR-003](0003-single-effect-game-state-commit.md) 中“持久后果必须由模组预定义并授权”的边界

现行设计要求重大持久后果预先存在于模组 `effect_definitions`，使 GM 只能解释输入、请求检定并从已有结果中选择效果。新版 MVP 改为由 GM 裁定虚构因果并建立正式世界事实；模组是提供背景、秘密、人物、张力与可能事件的参考书，不是 GM 能力或状态变化的白名单。即使模组没有预写对应场景、检定和效果，GM 也可以让合理的新路线与后果成为后续回合必须遵守的正式事实。

Agent Harness 仍负责 COC 机械、玩家决定权、结构一致性和持久化完整性，但不得仅因模组没有预定义某个后果而拒绝 GM。此决定不等于允许模型直接修改任意 JSON；通用世界变更工具、机械状态边界以及是否存在极少数不可变锚点，留待后续设计决定。

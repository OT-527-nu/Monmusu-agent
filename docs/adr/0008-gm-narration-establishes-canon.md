# ADR-008：GM 的明确叙述可以建立正典

- 状态：Accepted
- 日期：2026-07-26
- 决策关系：依赖 [ADR-007](0007-reference-becomes-canon-when-established.md)

会话 `SessionSetup` 显式载入的最小开场事实先成为本局正典；此后，GM 成功提交给玩家的明确事实叙述成为公开正典，GM 明确作出的隐藏裁定也可以在最终答复提交时成为隐藏正典。完整回合记录保留这些事实成立时的玩家输入、机械结果和 GM 输出，是发生争议或遗漏时的追溯依据。比喻、传闻、角色观点与刻意保留的不确定性不自动成为客观事实。

结构化事实只构成帮助后续 GM 回忆与检索的事实索引，不是决定叙述能否生效的许可层。即使某项明确叙述漏记于事实索引，它仍然有效，并可以依据回合记录补录；Harness 不得因为缺少预定义状态字段而把已经发生的虚构撤销。

# ADR-006：GM 选择机械，Harness 结算结果

- 状态：Accepted
- 日期：2026-07-26
- 决策关系：依赖 [ADR-005](0005-gm-authority-over-fictional-causality.md)，局部取代 [ADR-003](0003-single-effect-game-state-commit.md) 的模组预授权检定与效果边界

GM 在机械结果产生前决定是否需要 COC 机械、使用哪项机械，以及技能、难度、风险和伤害或理智损失等参数；这些决定依据当前虚构作出，不要求模组参考书预先定义对应目标、检定或效果。Agent Harness 验证工具参数，产生随机结果，计算成功等级与数值变化，并提交和记录机械结果。

GM 可以继续裁定机械结果在虚构中意味着什么，但不能在看到结果后改写目标值、骰点、成功等级或已经提交的数值变化。模组参考书可以建议典型检定与后果，却不是机械调用的授权来源；具体工具集合与参数结构留待后续设计决定。

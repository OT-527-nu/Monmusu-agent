# ADR-015：玩家拥有调查员的主动意志

- 状态：Accepted
- 日期：2026-07-26
- 决策关系：依赖 [ADR-005](0005-gm-authority-over-fictional-causality.md)

GM 拥有世界、NPC 和虚构因果的裁定权，玩家则拥有自己调查员的主动选择、台词、信念、情感承诺和关系决定。GM 可以补全执行玩家已声明意图所需的自然细节，也可以描述感官信息、环境与 NPC 反应以及已经产生的机械后果，但不能借补全动作替玩家增加新的重大选择。

COC 机械明确造成的昏迷、惊恐或失控可以暂时限制调查员行动，但必须来自真实机械结果。这一分工通过 GM 指令、示例与试玩验收表达，不建立输入意图分类器或逐句语义权限审核器。

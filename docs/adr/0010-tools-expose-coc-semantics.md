# ADR-010：工具直接表达通用 COC 机械

- 状态：Accepted
- 日期：2026-07-26
- 决策关系：依赖 [ADR-006](0006-gm-chooses-mechanics-harness-resolves.md)

GM 使用少量高层 COC 语义工具，例如技能或属性检定、理智检定与伤害结算。GM 决定何时调用、提供事前参数并解释结果；Harness 按 COC 规则产生和提交机械结果。工具不要求模组参考书预先定义目标或效果，也不包含某个模组的地点、NPC、时钟或剧情动作。

MVP 不把 `roll_dice` 与任意状态补丁作为主要 GM 接口，因为那会迫使模型自行实现规则并暴露数据结构；也不把现行 `effect_id` 白名单换成另一组模组专用工具。具体首批规则族根据最小可玩切片逐项决定，避免提前复刻整本 COC 规则书。

# ADR-021：MVP 是一局可收束的开放式短篇

- 状态：Accepted
- 日期：2026-07-26
- 决策关系：依赖 [ADR-019](0019-short-mvp-provides-full-game-record.md) 与 [ADR-020](0020-thalarion-becomes-an-open-reference-book.md)

MVP 保证从塔纳里昂开场困境开始并形成一次完整叙事收束，但不规定游戏时长、经过路线或结局类型。玩家可以采用参考书建议，也可以创造不同目标；逃脱、留下、交易、死亡、惊醒或 GM 根据本局因果形成的其他结果都可以结束短篇。GM 判断核心困境何时得到收束，玩家也可以明确要求继续或停止。

MVP 不设置 `ending_id`、预定义结局表或代码结束条件，也不承诺跨局成长、长期战役或跨模组记忆。这个边界限制首版产品跨度，不限制一局之内 GM 可以裁定的世界可能性。

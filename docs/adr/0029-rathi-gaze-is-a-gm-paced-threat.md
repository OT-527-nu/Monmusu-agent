# ADR-029：“拉提的注视”是 GM 主持的动态威胁

- 状态：Accepted
- 日期：2026-07-26
- 决策关系：依赖 [ADR-018](0018-fiction-state-is-a-natural-language-fact-ledger.md) 与 [ADR-020](0020-thalarion-becomes-an-open-reference-book.md)

模组参考书继续描述拉提的注意如何随喧闹、停留、亵渎或其他虚构原因逼近，并提供可借鉴的征兆与发展。GM 根据本局实际事件决定威胁何时升级、缓和或转向，通过叙事和自然语言事实表现当前压力，而不是匹配预定义的加减规则。

MVP 不保存六格 `threat_clock`，不提供模组专用推进工具，也不自动触发阶段事件。只有试玩证明 GM 无法稳定维持压力节奏时，才评估通用时钟能力；未来时钟只能作为 GM 主持工具，不能成为剧情许可或效果授权来源。

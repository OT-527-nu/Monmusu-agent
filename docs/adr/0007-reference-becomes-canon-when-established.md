# ADR-007：参考内容经 GM 确立后才成为正典

- 状态：Accepted
- 日期：2026-07-26
- 决策关系：依赖 [ADR-005](0005-gm-authority-over-fictional-causality.md)

模组参考书中的背景、秘密、人物与可能事件默认是参考条目，不因写在文件中就自动成为正式世界事实。会话创建时由最小 `SessionSetup` 显式载入维持游戏前提所需的开场事实；除此之外，GM 可以显式确立公开事实，也可以先确立仅自己可见的隐藏事实，尚未确立的参考条目可以随玩家行动被采用、改编或舍弃。

已经确立的事实属于本局正典，后续回合必须保持一致。它只能由新的虚构事件或合理揭示改变或重新解释，不能为了迁就参考书或预定剧情而静默改写。正式事实如何记录、投影和揭示留待后续设计决定。

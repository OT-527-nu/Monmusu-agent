# ADR-041：真实 GM 评估使用六个聚焦场景与完整试玩

- 状态：Accepted
- 日期：2026-07-26
- 决策关系：依赖 [ADR-011](0011-first-slice-proves-open-action-continuity.md)、[ADR-021](0021-mvp-is-one-open-ended-short-session.md) 与 [ADR-040](0040-live-gm-evaluation-uses-gates-and-human-rubric.md)

每个候选 GM 模型配置使用相同的六类短场景序列评估：接住模组未预写的合理破局；区分无需检定与确有风险的不确定行动；在失败后把孤注一掷或花费幸运的决定留给玩家；同时维持 NPC 主动性、隐藏机械与玩家意志边界；让新确立的事实在后续回合持续并能因虚构事件结束；接受交易、留下或其他参考书未预设的叙事收束。每个场景夹具必须明确初始事实、玩家输入序列、硬门槛和人工质量观察点，但不规定 GM 的固定文案或唯一正确剧情。

聚焦场景通过后，还必须完成至少一次开放式《逃离塔纳里昂》人工试玩，以观察多个能力组合后的整体体验。超时、步骤上限、无效 JSON、机械原子性和恢复幂等等可由假 adapter 稳定构造的 Harness 故障，继续留在确定性测试线，不为它们重复消耗真实 API 调用。

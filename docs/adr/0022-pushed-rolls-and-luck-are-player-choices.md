# ADR-022：孤注一掷与花费幸运由玩家选择

- 状态：Accepted
- 日期：2026-07-26
- 决策关系：依赖 [ADR-015](0015-player-owns-investigator-intent.md) 与 [ADR-017](0017-make-check-uses-character-sheet-and-coc-difficulty.md)

最终 MVP 在普通 COC 检定之外支持孤注一掷与花费幸运。失败后，玩家可以提出不同做法并主动要求孤注一掷；GM 必须在重掷前说明更严重的失败风险，Harness 关联原检定并结算新结果。规则允许时，玩家也可以明确决定花费幸运，Harness 验证适用性与余额并更新角色卡。

GM 可以向玩家说明这些机会，但不能替玩家自动使用，也不能在看到后续结果后补写选择。GM 负责从当前玩家自由文本理解是否明确选择孤注一掷或花费幸运；Harness 只验证机械前置、关联、点数和余额，不建设自然语言意图分类器。首个证明性切片仍只要求 `make_check`，孤注一掷与花费幸运作为后续 MVP 增量加入，不阻塞最早的真实 GM 两回合验证。

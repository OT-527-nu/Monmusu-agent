# ADR-019：短篇 MVP 每轮提供完整游戏记录

- 状态：Accepted
- 日期：2026-07-26
- 决策关系：依赖 [ADR-008](0008-gm-narration-establishes-canon.md) 与 [ADR-018](0018-fiction-state-is-a-natural-language-fact-ledger.md)

短篇 MVP 的每个回合都向 GM 提供本局完整游戏记录，包括不可变的会话开场记录、玩家输入、GM 叙事、事实变化和精简后的机械结果。事实索引用来突出当前仍有效的持续状态，但不替代历史，也不决定未被索引的既有叙述是否有效。记录不包含模型隐藏思维或内部推理。

MVP 不实现 Memory Agent、自动摘要、向量检索或固定的最近回合窗口。只有真实试玩证明完整记录造成不可接受的上下文长度、成本或注意力问题时，才根据证据引入压缩与按需回忆机制。

# ADR-013：短篇模组全文对 GM 可见

- 状态：Accepted
- 日期：2026-07-26
- 决策关系：依赖 [ADR-012](0012-module-reference-is-prose-first.md)

短篇 MVP 的 GM 在每个回合都可以读取完整模组参考书，而不是只接收 Harness 选出的当前场景投影。参考书提供全局人物、秘密、张力和可能发展；事实索引与回合记录则说明本局实际确立了什么。GM 负责结合两者判断哪些参考内容仍然适用。

MVP 不实现章节检索、向量数据库或按场景授权的内容投影。参考书保持在模型上下文可合理容纳的规模，并可利用稳定前缀缓存；只有未来真实内容规模证明全文上下文不可行时，才增加由 GM 主动使用的参考书搜索能力。
